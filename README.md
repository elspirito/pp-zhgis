# ПП-каталог рецептов

Удобный каталог рецептов, собранный по книге Никиты Игошева
«Книга рецептов. Руководство по вкусному похудению» (2025).

**113 рецептов · 11 разделов · фото к каждому блюду**

## Как открыть

Сайт статический, без сборки и интернета:

1. Откройте `index.html` двойным щелчком — всё работает из файла.
2. Или запустите локальный сервер из этой папки:

   ```bash
   python3 -m http.server 8765
   ```

   и откройте <http://127.0.0.1:8765/>.

## Что умеет

- **Поиск по названию и ингредиентам** — например, «творог», «лаваш», «курица».
- **Фильтры**: раздел книги, подборки («Много белка», «Быстро», «Хит», способ
  приготовления), калорийность на 100 г и минимум белка.
- **Сортировка**: как в книге, по калорийности, по белку, по алфавиту.
- **Карточка рецепта**: фото, КБЖУ на 100 г и на всё блюдо, примерный выход
  блюда, калькулятор порции, ингредиенты с чек-листом, пошаговое приготовление.
- **Варианты** — у составных рецептов (например, «Три блина на завтрак»)
  переключаются значения КБЖУ и подсвечиваются нужные ингредиенты.
- **Избранное** — сохраняется в браузере.
- **Список покупок** — ингредиенты добавляются из рецепта, отмечаются галочками
  и копируются одним текстом.
- **Тёмная тема**, горячие клавиши `/` (поиск), `Esc` (закрыть),
  `←`/`→` (предыдущий/следующий рецепт).
- Адаптивная вёрстка для телефона и компьютера.

## Структура

```
index.html            — страница каталога
assets/style.css      — оформление, тёмная тема, адаптив
assets/app.js         — поиск, фильтры, карточки, избранное, список покупок
assets/img/           — фотографии блюд (113 шт., извлечены из PDF)
data/recipes.js       — данные рецептов (JSON в window.COOKBOOK)
preview/              — скриншоты интерфейса
```

## Источник и оговорки

Все рецепты, фотографии и значения пищевой ценности взяты из книги
«Книга рецептов. Руководство по вкусному похудению» (Никита Игошев, 2025).
Данные извлечены из PDF автоматически и вычитаны вручную; в спорных местах
приоритет у текста книги. Калорийность и БЖУ приведены так, как в книге, и
могут отличаться от расчётов по конкретным продуктам.

Материал носит информационный характер и не заменяет консультацию врача
или нутрициолога.
