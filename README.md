# ПП-каталог рецептов

Удобный каталог рецептов, собранный по книге Никиты Игошева
«Книга рецептов. Руководство по вкусному похудению» (2025).

**113 рецептов · 11 разделов · фото к каждому блюду · работает офлайн**

**Живая версия:** <https://pp-recepty.vercel.app>
**Репозиторий:** <https://github.com/elspirito/pp-zhgis>

Деплой автоматический: пуш в `main` → Vercel собирает и публикует прод.

## Как открыть локально

Сайт статический, без сборки:

1. Откройте `index.html` двойным щелчком — каталог работает и из файла.
2. Для полноценного PWA (установка, офлайн-кэш) нужен http-сервер:

   ```bash
   python3 -m http.server 8765
   ```

   и адрес <http://127.0.0.1:8765/>.

## Мобильная версия

Интерфейс перестроен под телефон, а не просто «сжат»:

- **Нижняя навигация** из четырёх вкладок: Рецепты · Поиск · Избранное · Список.
  Всегда под большим пальцем, с бейджами количества.
- **Поиск — отдельная шторка** снизу: поле сразу в фокусе, результаты списком
  с фото и КБЖУ, недавние запросы, быстрые подборки. Нажатие на рецепт
  открывает его, а системная кнопка «назад» возвращает к результатам.
- **Карточка рецепта — на весь экран**: фото в шапке, при прокрутке появляется
  мини-заголовок, внизу закреплена панель «В избранное / В список покупок / Поделиться».
- **Фильтры и список покупок — нижние шторки** с ручкой: тянутся вниз и
  закрываются свайпом, фон затемняется и не прокручивается.
- **Крупные тач-цели**: кнопки ≥ 44 px, чекбоксы 20 px, строки списков ≥ 44 px.
- Учтены **safe-area** (вырез и домашний индикатор iPhone), `100dvh`,
  ландшафт и экраны от 320 px.
- **Системная кнопка «назад»** закрывает верхний слой, а не уводит со страницы.
- Тёмная тема, `prefers-reduced-motion`, отсутствие «залипающих» hover-эффектов.

## PWA

- `manifest.webmanifest` — имя, иконки (включая maskable), скриншоты,
  ярлыки «Поиск», «Избранное», «Список покупок».
- `sw.js` — service worker: оболочка и данные по stale-while-revalidate,
  фото по cache-first с ограничением объёма, навигация «сеть → кэш → офлайн».
- `offline.html` — запасная страница, если сети нет и кэш пуст.
- Своя **подсказка установки**: на Android/десктопе — через `beforeinstallprompt`,
  на iOS — инструкция «Поделиться → На экран Домой».
- **Обновления**: при выходе новой версии появляется полоса «Обновить»,
  перезагрузка происходит только по нажатию.
- Индикатор «нет сети» и полная работоспособность каталога офлайн.

Иконки пересобираются скриптом `python3 tools/make-icons.py`.

## Возможности каталога

- **Поиск** по названию и ингредиентам с учётом словоформ («яйца», «куриная грудка»).
- **Фильтры**: раздел книги, подборки («Много белка», «Быстро», «Хит», способ
  приготовления), калорийность и минимум белка на 100 г.
- **Сортировка**: как в книге, по калорийности, по белку, по алфавиту.
- **Карточка**: КБЖУ на 100 г и на всё блюдо, примерный выход, калькулятор порции,
  ингредиенты с чек-листом, пошаговое приготовление.
- **Варианты** составных рецептов переключают КБЖУ и подсвечивают нужные ингредиенты.
- **Избранное** и **список покупок** хранятся в браузере.
- Горячие клавиши: `/` — поиск, `Esc` — закрыть, `←`/`→` — соседний рецепт.

## Структура

```
vercel.json             — заголовки и кэш для хостинга
.vercelignore           — что не выкладывать на Vercel
index.html              — разметка каталога и слоёв
manifest.webmanifest    — манифест PWA
sw.js                   — service worker
offline.html            — офлайн-страница
assets/style.css        — оформление, тёмная тема, мобильный слой
assets/app.js           — поиск, фильтры, шторки, избранное, список, PWA
assets/img/             — фотографии блюд (113 шт.)
assets/icons/           — иконки PWA и favicon
data/recipes.js         — данные рецептов (window.COOKBOOK)
preview/                — скриншоты интерфейса
tools/make-icons.py     — генерация иконок
tools/screenshots.js    — пересборка превью (Playwright)
```

## Источник и оговорки

Рецепты, фотографии и значения пищевой ценности взяты из книги
«Книга рецептов. Руководство по вкусному похудению» (Никита Игошев, 2025).
Данные извлечены из PDF автоматически и вычитаны вручную; в спорных местах
приоритет у текста книги. Калорийность и БЖУ приведены так, как в книге, и
могут отличаться от расчётов по конкретным продуктам.

Материал носит информационный характер и не заменяет консультацию врача
или нутрициолога.
